# Нодовый AI

Интерактивный сайт, который объясняет работу нод: промпт → генерация изображения → готовый кадр → анимация → видео. Ноды соединяются и запускаются при прокрутке.

Открыть: https://nikatseplyaeva.github.io/nodovy-ai/

## Запуск и редактирование

Статический HTML, CSS и JavaScript, без сборки и внешних сервисов. Для локального просмотра выполните `python3 -m http.server 8000` в этой папке и откройте http://localhost:8000.

- `index.html`: тексты и структура.
- `style.css`: цвета, типографика и компоненты.
- `story.mjs`, `layout.mjs`: анимация и размещение нод.
- `app.js`: автозапуск, настройки видео и окно терминов.
- `assets/`: шрифты, изображение и видео.

Это интерактивный прототип на подготовленных файлах. AI API не подключён. Для двух движений камеры доступны готовые MP4 длиной от 3 до 10 секунд.

Шрифты Inter и Onest: SIL Open Font License 1.1. Лицензии приложены в папке `assets`. Источники: https://github.com/google/fonts/tree/main/ofl/inter и https://github.com/google/fonts/tree/main/ofl/onest .
